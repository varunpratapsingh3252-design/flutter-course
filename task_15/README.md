# Task 15 - Student Registration Form

## 📌 Objective
Develop a Flutter application that allows users to register student details using a form. The application validates user input, stores the entered information temporarily, and displays the submitted details in a success dialog.

---

## 🛠️ Features

- Student Registration Form
- Form Validation using `GlobalKey<FormState>`
- Text Editing Controllers
- Name, Email, Mobile, Roll Number, Course, and City fields
- Dropdown for Course Selection
- Reset Button to clear all fields
- Submit Button with validation
- Success Alert Dialog
- Displays entered student details after successful submission
- Clean and user-friendly Material Design UI

1. Clone the repository.

```

```

2. Open the project in Visual Studio Code or Android Studio.

3. Run the following command:

```

```

4. Connect an Android device or start an emulator.

5. Run the project:

