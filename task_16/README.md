# Task-16 - Student Information & Data Presentation Widgets

## 📌 Objective

Develop a Flutter application that demonstrates the use of the following widgets:

- SelectableText
- Table
- BottomSheet
- SnackBar

The application simulates a Student Information Portal where users can view student details, view a marksheet, perform actions through a BottomSheet, and receive feedback using SnackBars.

---

## ✨ Features

- Student Information Portal
- Student Details using SelectableText
- Student Marksheet using Table Widget
- Show Student Actions Button
- Modal Bottom Sheet
- SnackBar Notifications
- Bottom Navigation Bar
- Modern Material Design UI
