# Task 17 - Student Assignment Submission

## Objective

Develop a Flutter application that allows students to submit assignments using different Flutter widgets and packages.

---

## Features

- Assignment Details Screen
- Submit Assignment Screen
- Date Picker
- Time Picker
- File Picker
- Upload Progress Indicator
- Submission Success Screen
- Rating Screen
- Assignment Guidelines Screen
- Flutter Documentation using WebView
- Tooltip Demonstration
- Bottom Navigation Bar

---

## Widgets Used

- MaterialApp
- Scaffold
- AppBar
- Card
- Column
- Row
- ListTile
- ElevatedButton
- OutlinedButton
- BottomNavigationBar
- Image
- Icon
- Tooltip
- CircularProgressIndicator
- TextField
- AlertDialog
- Navigator

---

## Packages Used

- file_picker
- webview_flutter

---

## Learning Outcomes

- Navigation between multiple screens
- Working with DatePicker and TimePicker
- Selecting files using File Picker
- Displaying upload progress
- Using WebView
- Implementing Tooltip
- Building responsive Flutter UI
