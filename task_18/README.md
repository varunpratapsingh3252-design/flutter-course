# Task 18 - Student Placement Registration App

## Objective

Develop a Flutter application that allows students to register for campus placements. The application stores student information locally using SharedPreferences and retrieves it automatically when the application is reopened.

---

## Features

- Student Registration Form
- Student Image
- TextFields
- Dropdown Button
- Switch Widget
- SharedPreferences
- Save Student Details
- Retrieve Saved Details
- Dashboard Screen
- Success Registration Card
- Edit Student Details
- Delete Student Details

## Learning Outcomes

- Create forms using Flutter
- Store data locally using SharedPreferences
- Retrieve stored data automatically
- Navigate between screens
- Build responsive Flutter UI
- Use Dialogs and SnackBars
- Manage user input with TextEditingController
