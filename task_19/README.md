# Task 19 - Hive CRUD Update Student

## Objective

Develop a Flutter application using the Hive database to perform CRUD (Create, Read, Update, Delete) operations on student records. The application demonstrates local data storage using Hive and navigation between screens using Navigator.

---

## Features

- Add Student
- Display Student List
- Update Student Information
- Delete Student
- Local Storage using Hive
- Automatic UI Refresh using ValueListenableBuilder

---

## Technologies Used

- Flutter
- Dart
- Hive Database
- Hive Flutter
- Navigator
- Material UI

---

## How to Run

1. Clone the repository.
2. Run:

```
flutter pub get
```

3. Generate Hive Adapter:

```
dart run build_runner build
```

4. Run the application:

```
flutter run
```
