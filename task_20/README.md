## Objective

Develop a Flutter application that stores student information locally using SQLite. The application allows users to register students, save records into the SQLite database, view all registered students, update existing records, and delete records.

---

## Features

- Student Registration
- SQLite Local Database
- View All Students
- Search Student
- Update Student
- Delete Student
- Professional DataTable
- Form Validation
