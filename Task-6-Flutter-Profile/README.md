# Task 6 - Flutter Profile

## Objective

Create a Flutter Profile application using StatelessWidget and StatefulWidget.

## Features

- MyApp as StatelessWidget
- HomeScreen as StatefulWidget
- AppBar
- Profile Image
- Name
- Profession
- Email
- Follow Button
- setState() implementation

## Output

When the Follow button is pressed:
- AppBar title changes to Following.
- AppBar color changes from Blue to Green.
- Button text changes from Follow to Following.
