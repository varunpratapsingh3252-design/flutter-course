# Task 11 - Smart Café Ordering Screen

## Objective

Develop a Smart Café Ordering Screen using Flutter widgets and different button types.

## Features

- DropdownButton
- PopupMenuButton
- IconButton
- ElevatedButton
- OutlinedButton
- TextButton
- FloatingActionButton
- SnackBar
- Quantity Increase/Decrease

## Output

A Smart Café Ordering Screen where users can:
- Select food category
- Increase or decrease quantity
- View additional options
- Place an order
- Save for later
- Clear selection
